# Templates

| File | Use |
| --- | --- |
| [`config/capd.yaml`](config/capd.yaml) | Project configuration, every option commented |
| [`config/mapping.yaml`](config/mapping.yaml) | Map the metric data contract to the state's tables (`capd mapping views`) |
| [`azure-devops/capd-steps.yml`](azure-devops/capd-steps.yml) | Azure Pipelines step template |
| [`azure-devops/capd-publish-reports.yml`](azure-devops/capd-publish-reports.yml) | Daily report publication to a private reports repository |
| [`azure-devops/azure-pipelines.example.yml`](azure-devops/azure-pipelines.example.yml) | A complete example pipeline |
| [`github-actions/capd.yml`](github-actions/capd.yml) | GitHub Actions reusable workflow |

See the [vendor quickstart](../docs/quickstart.md).
